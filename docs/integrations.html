Integrations guide

Everything on this page works on the free plan today: the website widget, Telegram, WhatsApp/Instagram/Messenger through your own Meta app, WhatsApp through a self-hosted OpenWA gateway, the REST API with scoped keys, inbound events, and outbound webhooks for Zapier, Make, n8n or your own server. The WhatsApp options, with their trade-offs, are at the bottom.

1. Website chat widget

Add an AI chat bubble to any website. It answers from your knowledge box and flows, and every chat lands in your Inbox.

  1. Sign in and open Settings > Website chat widget.
  2. Create a key, optionally set a greeting and an allowed website, and copy the snippet:
<script src="https://chatora.us.ci/assets/widget.js" data-key="ck_YOUR_KEY" defer></script>

Paste it before </body>:

PlatformWhere to paste
WordPressInstall the free WPCode plugin, then WPCode > Headers & Footers > Footer. Or Appearance > Theme File Editor > footer.php.
BloggerTheme > Edit HTML, paste right before </body>, save.
ShopifyOnline Store > Themes > Edit code > Layout/theme.liquid, paste right before </body>.
Any other siteAny page, right before </body>.

If you set an allowed website on the key, the widget only loads on that origin.

2. Telegram bot (free, live)

  1. In Telegram, open @BotFather, send /newbot and copy the token it gives you (looks like 123456789:AA...).
  2. In Chatora open Settings > Channels > Telegram, paste the token and connect. Chatora registers the webhook for you.
  3. Message your bot. It answers from your knowledge box and flows (trigger /start or keywords), and every chat appears in your Inbox. Contacts can reply STOP to unsubscribe from broadcasts.

3. Zapier

Trigger (Chatora → Zapier): New Zap > Webhooks by Zapier > Catch Hook > copy the URL > in Chatora open Settings > Developers and API > Webhooks, pick the event and paste the URL. Send a test (for example, message your Telegram bot) and Zapier sees the payload. Events: contact.created, message.received, event.received, flow.finished.

Action (Zapier → Chatora): Webhooks by Zapier > POST:

URLhttps://chatora.us.ci/api/v1/events
Payload typejson
Dataevent = tag-applied, handle = the email or tg: id, name, key = the tag (for example new-customer)
HeadersAuthorization = Bearer chk_live_YOUR_KEY

The API key needs the events:write scope. A tag event starts every live flow whose trigger is event:tag-applied <tag>. To add contacts instead, POST to /api/v1/contacts with a contacts:write key.

4. Make (Integromat)

Trigger: add a Custom webhook module, copy its URL, add it in Chatora Settings > Webhooks as above. Action: add an HTTP > Make a request module: method POST, URL https://chatora.us.ci/api/v1/events, header Authorization: Bearer chk_live_YOUR_KEY, body type Raw, content type application/json, body like {"event":"tag-applied","handle":"{{1.email}}","key":"vip"}.

5. n8n

Trigger: add a Webhook node, use its production URL, and register it in Chatora Settings > Webhooks (or with POST /api/v1/hooks). Action: add an HTTP Request node: POST https://chatora.us.ci/api/v1/events, authentication = Generic Credential Type > Header Auth (Authorization: Bearer chk_live_YOUR_KEY), JSON body with event, handle and key. Self-hosted n8n works too; the webhook target must be a plain https URL without a custom port.

6. Google Sheets → Chatora (free, Apps Script)

Adds new sheet rows as Chatora contacts. In the sheet: Extensions > Apps Script, paste this, set KEY, then Triggers (clock icon) > Add Trigger > onRowAdded > From spreadsheet > On form submit (for Google Forms) or onEdit for manual entry.

var KEY = "chk_live_YOUR_KEY"; // needs the contacts:write scope
function onRowAdded(e) {
  var row = e.range.getValues()[0];
  UrlFetchApp.fetch("https://chatora.us.ci/api/v1/contacts", {
    method: "post", contentType: "application/json",
    headers: { Authorization: "Bearer " + KEY },
    payload: JSON.stringify({
      name: String(row[0] || "Sheet contact"),
      handle: String(row[1] || ""),
      channel: "sheets", tags: ["from-sheet"]
    }),
    muteHttpExceptions: true
  });
}

7. Google Calendar → Chatora (free, Apps Script)

Tags contacts when they appear as guests on new calendar events, which can start a confirmation flow. At script.google.com: New project, paste this, set KEY, then Triggers > Add Trigger > syncCalendar > Time-driven > every hour.

var KEY = "chk_live_YOUR_KEY"; // needs the events:write scope
function syncCalendar() {
  var props = PropertiesService.getScriptProperties();
  var since = new Date(props.getProperty("since") || Date.now());
  var now = new Date();
  CalendarApp.getDefaultCalendar().getEvents(since, now).forEach(function (ev) {
    ev.getGuestList().forEach(function (g) {
      var email = g.getEmail(); if (!email) return;
      UrlFetchApp.fetch("https://chatora.us.ci/api/v1/events", {
        method: "post", contentType: "application/json",
        headers: { Authorization: "Bearer " + KEY },
        payload: JSON.stringify({ event: "tag-applied", handle: email,
          name: g.getName() || email, key: "booked-call", channel: "calendar" }),
        muteHttpExceptions: true
      });
    });
  });
  props.setProperty("since", now.toISOString());
}

8. Outgoing webhooks from a flow

Flows have a built-in Webhook step: paste any https URL and when a contact passes that step Chatora POSTs their JSON (name, handle, channel, tags, fields). Use it for per-flow alerts (CRM, email tools, your own server) without any API key. Up to 3 webhook calls per run, 5 second timeout.

9. WhatsApp: three ways, free to start

Option A — WhatsApp Cloud API (official, self-serve)

Dashboard → Channels → WhatsApp: connect your own Meta app credentials (phone number ID + access token; Meta reviews your app, not Chatora). Replies from flows, the AI agent and the inbox, with Meta's 24-hour reply window enforced. A test mode simulates the channel before you connect real credentials. This is the compliant path; Meta bills message fees directly to your Meta account.

Option B — OpenWA gateway (self-hosted, unofficial)

OpenWA is a free, open-source (MIT) WhatsApp gateway you run yourself with Docker. It keeps a WhatsApp Web session alive and exposes a REST + webhook API; Chatora connects to it as an optional channel: inbound messages reach your flows and AI replies, and outbound sends go through it.

Read this first (the honest catch): OpenWA is unofficial: not approved by Meta, built on a reverse-engineered client. WhatsApp can restrict or ban the connected number, and the project itself warns about this. So:

  • Use a dedicated SIM/number you can afford to lose. Never your main business number, never your personal one.
  • Reply to people who messaged you first or opted in, keep volumes modest, and honor STOP (handled automatically).
  • If losing the number would hurt, use Option A instead.

Setup (about 15 minutes)

  1. Run the gateway on any computer or small VPS with Docker: docker run -d --name openwa -p 3000:3000 -e WA_API_KEY="pick-a-long-random-key" rmyndharis/openwa:latest (exact image name and flags are in the OpenWA README).
  2. Expose it over HTTPS (Chatora can only reach https URLs). The free way is a Cloudflare Tunnel: cloudflared tunnel --url http://localhost:3000 gives a free https://....trycloudflare.com address, or map a subdomain you own.
  3. Create a session in the OpenWA dashboard (e.g. main) and scan the QR code with the dedicated number's WhatsApp app (Settings → Linked devices).
  4. Connect in Chatora: Dashboard → Channels → WhatsApp (OpenWA), paste the https URL, API key and session ID. Chatora verifies them and registers its webhook with your gateway automatically.

Once connected: inbound WhatsApp messages match your flows (keywords, menus, AI replies), STOP applies, the contact cap applies, and messages are logged like other channels. Broadcasts can target the OpenWA channel from the channel picker.

Option C — click-to-chat links (zero setup)

Put https://wa.me/2010XXXXXXXX?text=Hello anywhere (flows, website buttons, broadcasts): it opens a WhatsApp chat with that number. Use your own number to collect leads. No automation, but zero risk and zero setup.

Instagram DM and Messenger automation are also live in Dashboard → Channels with your own Meta app credentials, and through the done-for-you service.
