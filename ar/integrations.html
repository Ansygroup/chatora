تيليجرام ودردشة الموقع يعملان · التكاملات على الخريطة

خطّط لكيفية ربط أدواتك مستقبلًا

ربط بوتات تيليجرام وودجت دردشة الموقع متاح اليوم من الإعدادات في المعاينة. الخدمات أدناه أمثلة مستقبلية وليست تكاملات مفعّلة: لا يوجد ربط بمتاجر أو مدفوعات أو CRM أو أتمتة أو API عامة بعد.

لا يتوفر أي تكامل مع طرف ثالث بعد؛ تيليجرام ودردشة الموقع ميزتان مدمجتان وليستا تكاملات خارجية. أسماء الخدمات أدناه أهداف محتملة مستقبلًا فقط؛ لا يوجد لها اتصال أو مزامنة أو webhook أو إرسال رسائل مفعّل.

التجارة

أمثلة مستقبلية محتملة: Shopify وWooCommerce وBigCommerce وSalla وZid وMagento. مزامنة المنتجات والمخزون والطلبات والسلات غير متاحة بعد.

المدفوعات

أمثلة مستقبلية محتملة: Stripe وPaymob وFawry وTap وPayTabs وPayPal. روابط الدفع وتأكيد الدفع عند الاستلام ومزامنة الاسترداد غير متاحة بعد.

إدارة العملاء والدعم

أمثلة مستقبلية محتملة: HubSpot وZoho وPipedrive وFreshdesk وIntercom. مزامنة العملاء والملاحظات وتذاكر الدعم غير متاحة بعد.

الأتمتة والبيانات

أهداف مستقبلية محتملة: Zapier وMake وn8n وGoogle Sheets وAirtable وNotion وBigQuery. المشغّلات وتصدير أحداث المحادثات غير متاحين بعد.

واجهة المطورين (غير متاحة بعد)

لا توجد واجهة REST عامة أو webhooks أو SDK أو بيئة مطورين مفعّلة في المعاينة الحالية.

هل لديك تكامل مقترح؟ أرسل اقتراحك عبر صفحة التواصل. لا يوجد جدول زمني مضمون للتنفيذ. تواصل مع Chatora
