استكشف معاينة المنتج قارن مع ManyChat

ملاحظة التوفر: تتضمن الصفحة مفاهيم مستقبلية وواجهات توضيحية، وليست قائمة بميزات تعمل حاليًا. تدعم المعاينة حسابات بكلمة مرور ومسودات تدفقات و45 مسودة بداية قابلة للتعديل بخطوات عامة مؤقتة غير مختبرة للإنتاج، وأدوات CSV لجهات الاتصال واختبارات محلية ومعاينة جمهور البث. لا توجد ردود ذكاء اصطناعي مباشرة أو قنوات مراسلة متصلة أو رسائل صادرة أو تكاملات تجارة أو تحليلات منتج.

01 · الوكيل الذكي

تصوّر مستقبلي: ذكاء اصطناعي يستند إلى كتالوجك

قد يستخدم إصدار مستقبلي ملف المنتجات والأسئلة الشائعة وصفحات السياسات كمراجع. لا يوجد في المعاينة مزوّد ذكاء اصطناعي أو بحث مباشر في المنتجات أو المخزون أو الأسعار أو الشحن.

  • إجابات موثّقة مخططة: الاستناد إلى الكتالوج أو الأسئلة الشائعة مع ضوابط للسعر والادعاءات؛ غير متاحة حاليًا
  • توجيه النية المخطط: تمييز التصفح وأسئلة السعر وطلبات التحويل لموظف؛ غير متاح حاليًا
  • تحويل بشري مخطط: توجيه بعض الطلبات إلى موظف؛ غير متاح حاليًا
  • دعم لغات مخطط: واجهتا العربية والإنجليزية متاحتان؛ ردود الذكاء الاصطناعي ومطابقة اللهجات غير مفعّلة

02 · الأتمتة

أتمتة التدفقات: تصوّر ضمن خارطة الطريق

قد تساعد الأوامر النصية مستقبلًا في إعداد مسودة لمسار. تتيح المعاينة الحالية تعديل خطوات المسودة يدويًا فقط؛ ولا تُنشئ تدفقات من الأوامر أو تفعّل محفزات أو تشغّل أتمتة.

  • المحفزات المخططة تشمل التعليقات والرسائل وإشارات القصص ونقرات الإعلانات والكلمات وwebhooks؛ لا يوجد منها اتصال نشط هنا
  • 45 مسودة بداية قابلة للتعديل بخطوات عامة مؤقتة؛ غير مختبرة للإنتاج وليست أتمتة جاهزة
  • يمكن حفظ خطوات انتظار في المسودات؛ قواعد ساعات الهدوء حسب المنطقة الزمنية غير منفذة
  • سجل الإصدارات والرجوع بنقرة واحدة غير متاحين في المعاينة

03 · صندوق موحّد

الصندوق الموحّد: اتجاه مستقبلي للمنتج

الصندوق الموحد مفهوم مستقبلي. لا تتصل المعاينة حاليًا بإنستجرام أو واتساب أو تيك توك أو ماسنجر أو تيليجرام أو SMS أو البريد أو دردشة الويب.

  • لا تجمع المعاينة الرسائل والطلبات والوسوم والملاحظات عبر القنوات في ملف موحّد للعميل
  • لا تتوفر مكتبة ردود محفوظة أو مسودات يكتبها الذكاء الاصطناعي؛ ولا يوجد مزوّد ذكاء اصطناعي متصل
  • قواعد التوزيع وأتمتة اتفاقيات مستوى الخدمة وكشف تعارض الردود غير مفعّلة
  • مقاعد الفريق وحدود الخطط غير معلنة؛ المعاينة مرتبطة بالحساب المسجّل فقط

واجهة توضيحية فقط — لا تعرض جهات اتصال أو محادثات حقيقية.

04 · الرسائل الجماعية

تخطيط البث: تقسيم ومراجعة وقياس

قد يتيح اتجاه المنتج مستقبلًا استهداف شرائح محفوظة وتحديد نوافذ الإرسال. تعرض المعاينة جمهور جهات الاتصال فقط؛ ولا تحسّن التوقيت أو تطبق حدود التكرار أو ترسل رسائل.

  • تحسين وقت الإرسال لكل جهة اتصال غير متاح
  • اختبارات A/B واختيار الفائز تلقائيًا غير متاحين
  • مراجعة أو اعتماد قوالب واتساب من لوحة التحكم غير متاح
  • إسناد الإيراد لكل حملة غير متاح

05 · التجارة

تصوّر مستقبلي: ربط أسئلة المنتج بالدفع

قد يربط تكامل تجارة مستقبلي بيانات المنتج والكتالوج والدفع. لا يوجد Shopify أو WooCommerce أو Stripe أو أي موصل تجارة آخر مفعّل في المعاينة؛ ولا يتوفر إسناد للطلبات.

  • فحص المخزون ومتغيرات المنتج مباشرة غير متاح
  • استرجاع السلال آليًا وروابط الدفع الفريدة المؤقتة غير متاحين
  • تكاملات الدفع عند الاستلام والمحافظ الإقليمية غير متاحة
  • تحديثات ما بعد الشراء وطلب التقييم وتذكير إعادة الطلب غير مفعّلة

06 · التحليلات

تحليلات مستقبلية: ربط المحادثات بالنتائج

لا تربط المعاينة أحداث الطلبات أو بيانات القنوات؛ لذلك لا تحسب إيرادًا منسوبًا أو حل التذاكر أو جودة الذكاء الاصطناعي.

  • إسناد الإيراد حسب التدفق والوكيل والكلمة والقناة والحملة غير متاح
  • تقارير حل التذاكر تلقائيًا أو خفضها غير متاحة
  • بطاقات جودة الذكاء الاصطناعي وإشارات الهلوسة غير متاحة

07 · الثقة والأمان

تحقّق من ضوابط الأمان قبل الاعتماد عليها

هذه المعاينة ليست شهادة أمان أو اتفاقية مستوى خدمة. لا توجد قنوات مراسلة متصلة؛ راجع إشعار الخصوصية قبل إدخال البيانات.

حالة واجهات API الرسمية

اتجاه المنتج يفضّل الواجهات الموثقة والمعتمدة. لم يتم التحقق من وجود تكامل قناة خارجي أو اعتماد شريك من Meta لهذه المعاينة.

الخصوصية ومكان تخزين البيانات

لم تُنشر قائمة موثقة بمناطق الاستضافة أو اتفاقية DPA موقعة أو مواصفات التشفير في التخزين أو شهادات الأمان؛ راجع الإشعار القانوني.

التزامات التوفر

لم يتم التحقق أو الوعد بنسبة تشغيل 99.99% أو بتكرار متعدد المناطق أو بصفحة حالة عامة.

معالجة بيانات الذكاء الاصطناعي

لا يوجد مزوّد ذكاء اصطناعي متصل ولا معالجة خارجية مفعّلة. لا ترسل بيانات حساسة؛ ولم تُحدد هنا شروط أي مزوّد مستقبلي.

سجلات التدقيق وSSO

صلاحيات الأدوار وسجلات التدقيق غير القابلة للتغيير وSSO غير متاحة في المعاينة؛ ولا يتم تسويق نموذج صلاحيات للفريق.
